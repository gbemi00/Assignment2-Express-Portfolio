# Assignment 2 - ExpressJS Portfolio

## Student

## Project Description
This project is a personal portfolio website created using Node.js, ExpressJS, and EJS templates. The portfolio contains Home, About Me, Projects, and Contact Me pages.

## Technologies Used
- Node.js
- ExpressJS
- EJS
- Bootstrap
- Font Awesome
- CSS
- Git and GitHub
- Render

## Project Structure
The project was created using Express Generator with EJS as the view engine. Express routes are used to render the portfolio pages. Shared EJS partials are used for the navigation/header and footer. Images, stylesheets, and other static assets are stored in the public folder.

## External Resources
Bootstrap was used for responsive layout, navigation, and styling.

Font Awesome was used for the GitHub and LinkedIn icons.

Bootstrap: https://getbootstrap.com/

Font Awesome: https://fontawesome.com/

## Deployment
The application is deployed using Render.
